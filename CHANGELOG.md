# Changelog

## Unreleased

- **Terms are listed, never marked.** Claude lists the terms under `▸ Terms`, written as in the text, and the display mod underlines them in place, so no `{{…}}` braces show up on the web, in the `ctrl+o` transcript or in exports. Old replies with marks still work.
- **On the web:** a cloud session (`CLAUDE_CODE_REMOTE=true`) gets the plain layout: the story, then `▸ Technical: "tech"` on request, and the term list as a short glossary. For Remote Control from claude.ai, `shoga web on` does the same for the session; `shoga web off` folds again.
- The quality check flags a question or a "more detail" offer inside the folded technical part, where nobody sees it.

## 0.3.1

- **Term hints sit inside the answer.** On the terminal the term is underlined in place and its card opens on hover, over the reply, on a solid background that no longer clips; desktop, VS Code and mobile open it with a click. The footer of term chips is gone.
- Terms Claude only listed under `▸ Terms` are now found in the text and highlighted; listed terms that are not in the reply are dropped.
- The story starts from what the reader does not know yet, one line per point that applies: for their own code, the verdict and what is new (proof, risk, gap); for code new to them, the problem first; when you built it together, what works now and how. When unsure, one line of the problem. A closing question goes before `▸ Technical`, so it is never folded away.
- The session knows who the user is, from local git and gh config (name, email, GitHub login; no network), so Claude can tell the user's own code from code that is new to them. Code Claude writes in the session counts as new, even under the user's name.
- The quality check looks for hard words and mixed scripts in the whole reply again; only the length counts the part shown.
- New shortcut `huh` for "explain it simpler": a `?` typed into an empty prompt opens Claude Code's shortcut help. `??` still works.

## 0.3.0

- **Story first, tech folded**: replies start with the plain story for your role; the technical part, in full sentences and with what your role checks (code for Dev, repro steps for QA, scope for PO …), is folded under `▸ Technical`. `tech` unfolds every one (without the display mod, it asks Claude for it).
- Setting `layers`: `story` (default), `technical` (technical part first, story folded, `story` unfolds it) or `technical-only`.
- Rule: **seedhi baat, no bakwas**, straight to the point, nothing extra.
- **Term hints** replace the hover glossary: Claude marks up to 5 words you may not know and gives their meaning here; a click opens a card over the reply instead of a new line. Setting `term_hints` (`on` by default, for every role).
- The length check counts the story only.
- New banner: a Claude Code window where a developer, QA tester, product owner and support agent ask about the same payment bug in Roman-Urdu, English, Dutch and Hinglish. With the Shoga-Speaks switch off the answer is a 400-word wall; Shoga flies over from the wordmark, switches it on, and the answer becomes two plain lines with a clicked term hint and the technical part folded under `▸ Technical` (an 81 s loop timed for reading, a still under reduced motion; pure SVG, 150 KB). New logo: the coloured Shoga on a switch, with a head close-up at 64 px and below (7 KB). Social preview 1280×640. Built with `python3 assets/src/banner.py` (`--png` for the social preview) and `python3 assets/src/build.py` (logo; `--vendor-fonts` refreshes the font subsets in `assets/src/fonts/`).

## 0.2.0

- **Display mod** (Claude Code 2.1.287+): fold and unfold the other language under each reply, translated on demand; `en` / `tr` without a Claude turn; plain-language lines under approval dialogs and tool rows; hover glossary; status line.
- **Plain-language approvals** for risky shell commands, in 6 language variants.
- **Failures explained**: failing tests and builds get one plain line for your role.
- **Quality check** after every reply: hard words, mixed scripts, length, code for non-developer roles.
- **Learns your level**: `??`, `shoga simpler`, `shoga deeper`, `shoga know`.
- New mascot, **Shoga**: an animated banner where Shoga gives one message each to Dev, QA and PO, in Roman-Urdu, Dutch and English. White background, 28 KB. Generated by `assets/src/build.py`.
- New docs.
