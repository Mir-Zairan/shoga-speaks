# Security

Shoga-Speaks runs hooks on your machine. They read your settings and Claude's replies, and write only to `~/.claude/shoga-speaks/`. They make no network calls. The display mod calls Claude's own model API through Claude Code to translate text you ask to see.

To report a vulnerability, open a private [security advisory](https://github.com/Mir-Zairan/shoga-speaks/security/advisories/new). Please don't open a public issue.
