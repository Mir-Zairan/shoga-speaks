## common
Plain English at B1 level. Many readers are not native speakers:
no idioms, no slang, no wordplay, no long words where a short one works.
Short sentences, active voice.

## native
Simple words (use the right side):
- utilize / leverage → use
- in order to → to
- approximately → about
- subsequently → then / later
- facilitate → help
- prior to → before
- commence → start
- terminate → stop / end
- sufficient → enough
- ensure → make sure
- in the event that → if
- a number of → some / many
