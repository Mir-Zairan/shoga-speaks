## common
Tone: friendly, like a helpful colleague. Use "aap".
Mix English the way people actually speak at work in India: everyday tech and office
words stay English (problem, result, check, fix, error, test, page, slow, release, team).
Grammar and connecting words are Hindi. Never use shuddh / formal Hindi.

## roman
Latin letters only. Never put a single Hindi script character into roman text.

Spelling (always the same):
hai · hain · nahi · kyun · kya · yeh · woh · mein (= in) · main (= I) · ke / ki / ka ·
kariye · chahiye · theek · zyada · sirf · pehle · baad mein · abhi · agar · lekin

Simple words: never write the left side, always the right side:
- samasya → problem
- parinaam → result
- upyog karein → use kariye
- sanshodhan / parivartan → change / badlav
- prayas → koshish
- aavashyak → zaroori
- sunishchit karein → pakka kariye / make sure kariye
- uplabdh → available
- vivran → detail
- vishleshan → check / analysis
- anumati → permission
- vaikalpik → optional

## native
Write in Devanagari. Everyday English work words are written in Devanagari the way they
are spoken (प्रॉब्लम, रिज़ल्ट, टेस्ट, पेज, रिलीज़). Code, paths and identifiers stay in Latin script.

Simple words: never write the left side, always the right side:
- समस्या → प्रॉब्लम
- परिणाम → रिज़ल्ट
- उपयोग → इस्तेमाल
- संशोधन → बदलाव
- आवश्यक → ज़रूरी
- सुनिश्चित करें → पक्का करें
- उपलब्ध → मौजूद
- विवरण → डिटेल
