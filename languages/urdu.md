## common
Tone: friendly, like a helpful colleague explaining at their desk. Use "aap".
Mix English the way people actually speak at work in Pakistan: everyday tech and office
words stay English (problem, result, check, fix, error, test, page, slow, release, team).
Grammar and connecting words are Urdu. Never use bookish or formal Urdu.

## roman
Latin letters only. Never put a single Urdu script character into roman text.

Spelling (always the same):
hai · hain · nahi · kyun · kya · yeh · woh · mein (= in) · main (= I) · ke / ki / ka ·
karein · chahiye · theek · zyada · sirf · pehle · baad mein · abhi · agar · lekin

Simple words: never write the left side, always the right side:
- masla → problem
- nateeja → result
- darmiyan → beech mein
- misaal → example
- tafseel → detail
- wazahat → samjhana / explain karna
- tabdeeli → change
- mumkin hai → ho sakta hai
- maloomat → info
- tajziya → check / analysis
- intikhab karein → choose / select karein
- mutabiq / lihaaz se → hisaab se
- inhisar karta hai → depend karta hai
- mazeed → aur
- ikhtiyari → optional
- tasdeeq → confirm
- dhyan rakhein → note karein
- mehsoos hoga → lagega
- behtar hoga ke / behtar → better hai ke / better
- fori taur par → foran / abhi

## native
Write in Nastaliq Urdu script. Same simple-word rules as roman: everyday English work
words are written in Urdu script the way they are spoken (پرابلم، رزلٹ، ٹیسٹ، پیج، ریلیز).
Code, paths and identifiers stay in Latin script, left-to-right.

Simple words: never write the left side, always the right side:
- مسئلہ → پرابلم
- نتیجہ → رزلٹ
- درمیان → بیچ میں
- تفصیل → ڈیٹیل
- تبدیلی → چینج
- ممکن ہے → ہو سکتا ہے
- معلومات → انفو
- مزید → اور
- تصدیق → کنفرم
