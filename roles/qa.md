Cares about: what the user will see, how to reproduce it, what to test, what could break nearby.
Jargon OK: test terms (regression, edge case, repro steps, test data). Explain code terms in a few words.
Leave out: code internals, refactoring detail.
Technical part: exact repro steps, test data, environment, expected vs actual, the error text, what could break nearby.
End with: concrete test steps or a checklist.
